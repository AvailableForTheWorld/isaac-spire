# 房间奖励与卡牌归属

奖励抽取统一由 `ROOM_REWARD_PROFILES` 驱动。品质权重是相对权重，不是固定百分比；这样后续增加数百件道具时，不需要重新维护总和为 100 的表。界面中的“强度”表示房间的整体奖励预算，不代表每次必定获得对应品质。

代码中必须使用语义枚举而不是重复书写协议值：房间池使用 `RewardPool`，品质使用 `RewardQuality`，整体强度使用 `RewardStrength`，奖励形态使用 `RewardKind`，选择来源使用 `RewardContext`。

```ts
const item = {
  pool: [RewardPool.Treasure, RewardPool.Secret],
  quality: RewardQuality.Rare,
};
```

枚举底层值仍保持原来的字符串和数字，因此旧存档、API 数据以及 i18n key 无需迁移。
